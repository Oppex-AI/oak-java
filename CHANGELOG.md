# Changelog

All notable changes to OAK are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html). See [RELEASING.md](RELEASING.md).

Entries are grouped: **Added**, **Changed**, **Fixed**, **Security**, **Tools**
(new/changed capabilities — input, output, or permission), **Dependencies**. Trivial
internal changes don't need an entry.
